# HUMBLE MUSIC website — visual refresh

This refresh keeps the existing Vite/vanilla-JS structure, release manifest, routes, download architecture links, 15-second download modal, ad placements, legal pages and existing app screenshots.


## Design direction
- Restrained charcoal palette with a muted lavender accent
- Editorial typography and deliberate spacing
- Clear hierarchy, responsive layouts and accessible controls
- Reduced decorative effects; no generic AI-style visual motifs
- Responsive mobile navigation and download cards

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The source JS was syntax-checked with Node. The production build could not be run in the current environment because Vite dependencies were not available and dependency installation timed out.
